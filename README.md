# Aburime-Sound-Manager
A professional audio processing tool with advanced transcription capabilities built with JavaFX and WhisperX. The app features batch file processing, transcription with speaker diarization, REST API, performance reporting and monitoring, realtime progress tracking, volume analysis &amp; optimization, etc.
